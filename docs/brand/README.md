# 브랜드 마크 — Take a Look

진녹 타일 아래에서 올라와 **옆을 살펴보는 고양이**. 서비스 이름("살펴보다")을 그림 한 장으로 옮겼다.
단순한 기하 도형(사각형·삼각형·원)으로 새로 그렸고, 밈 사진·기존 캐릭터·다른 브랜드 마스코트를 참고하지 않았다.

## 후보와 선택

`candidates/`의 3안을 16·32·180·512px, 라이트(#f5f5f7)·다크(#1c1c1e) 배경에 나란히 놓고 비교했다(`comparison.png`).

| 안 | 모양 | 작은 크기 판독성 | 단순함 | 색 규칙 |
|---|---|---|---|---|
| A `a-face.svg` | 둥근 턱의 고양이 얼굴, 연두 눈 | 16px에서 귀와 얼굴이 한 덩어리로 뭉친다 | 좋음 | 다크 배경에서 진녹이 묻혀 색을 바꿔야 한다 |
| B `b-over-line.svg` | 가로선 위로 머리만 내민 고양이 | 16px에서 선과 머리가 붙어 보인다 | 좋음 | A와 같음 |
| **C `c-tile.svg` (선택)** | 진녹 타일 아래에서 올라온 흰 고양이, 옆을 보는 눈 | **16·32px에서 가장 또렷하다**(꽉 찬 타일 + 흰 윤곽) | 좋음 | 타일이 스스로 배경이라 어느 배경에서도 형태가 유지된다 |

판단 순서는 작은 크기 판독성 → 단순함 → 색 규칙이다. 탭 아이콘(16px)에서 고양이로 읽히는 것은 C뿐이라 C를 골랐다.
`c-tile-16.svg`는 16px 전용 단순형이다(눈을 빼고 귀·머리 윤곽만, 좌표를 픽셀 격자에 맞춤).

## 사용 규칙

- **색**: 타일 진녹 `#124532`(`--color-logo-tile`), 얼굴 흰색(`--color-logo-face`), 눈동자 연두 `#8DC63F`(`--color-logo-eye`). 연두는 눈동자 한 곳에만 쓴다.
  주황(주의 전용), 적·청(가격 방향 전용), 성균 파랑 `#072A60`, 교표 모티프는 쓰지 않는다.
- **다크 배경**: 진녹 타일은 `#1c1c1e` 위에서 1.6:1로 묻히므로 `--color-logo-tile-on-dark` `#2f7a5c`(3.3:1, 흰 얼굴과 5.2:1)를 쓴다.
  지금은 탭 아이콘(`app/icon.svg`의 `prefers-color-scheme`)만 해당한다. 앱에는 아직 다크 테마가 없다.
- **최소 크기**: 16px. 20px 이하는 단순형(`LogoMark`가 자동 전환), 24px 이상은 눈이 있는 기본형.
- **여백**: 마크 주변에 마크 폭의 1/4 이상. 워드마크에서 마크와 글자 사이도 마크 폭의 1/4(`Wordmark`).
- **하지 말 것**: 타일 모서리 반경·비율 변경, 그림자·그라데이션·테두리, 고양이만 떼어 쓰기, 색 반전(흰 타일 + 진녹 고양이).
