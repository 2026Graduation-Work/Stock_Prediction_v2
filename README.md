# Stock-Prediction

행동재무학 기반 심리 지수 반영 주가 예측 모델 및 웹 플랫폼

성균관대학교 소프트웨어학과 2026학년도 졸업작품

## 프로젝트 개요

전통적인 퀀트 트레이딩 시계열 모델은 과거 데이터 패턴에 의존하기 때문에
거시경제적 충격 상황에서 한계를 보인다. 본 프로젝트는 행동재무학 기반의
투자 심리 지수를 예측 모델에 결합하고, 그 결과를 금융 지식이 부족한
일반 사용자도 직관적으로 이해할 수 있는 웹 플랫폼으로 제공한다.

핵심 키워드: 행동재무학 · 일반인 접근성 · 화이트박스 모델(설명 가능한 AI)

## 팀 구성 및 역할

| 블록 | 담당 | 역할 |
| --- | --- | --- |
| 🟡 yellow | 중현 | 사용자 내부 정보 — 설문, JSON 스키마 |
| 🟢 green_cv | 진세 | 차트 패턴 분석 (기술적 분석, DT 계열 모델) |
| 🟢 green_llm | 서환 | 뉴스 감성·재무제표·SNS 심리 분석 |
| 🔵 blue | 성우 | 기능 명세, API, 대시보드, 인프라 |

## 디렉토리 구조

```
/docs        프로젝트 문서 (회의록, 설계 문서)
/schema      블록 간 공유 인터페이스 스키마 (JSON)
/yellow      노란색 블록 — 설문, 사용자 프로파일링
/green_cv    초록색 블록 — 차트/기술적 분석
/green_llm   초록색 블록 — 뉴스/재무제표/SNS LLM 분석
/blue        파란색 블록 — 대시보드, API, 인프라
```

## 기술 스택

- Web: Next.js (App Router) + Vercel
- 언어: TypeScript / 모델링 Python
- DB: Supabase (PostgreSQL + pgvector)
- 시각화: Recharts
- 스타일: Tailwind CSS
- 시장 데이터: yfinance, KRX API
- LLM: Claude API / OpenAI API
