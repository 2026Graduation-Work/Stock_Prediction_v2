# 차트 대표 실험 결과

이 문서는 chart 실험 결과의 요약 정본이다. 아래 수치는 과거 데이터 기반
백테스트·검증 결과이며 미래 수익을 보장하거나 매매를 지시하지 않는다.
날짜순 작업 이력과 현재 상태는 [`PROGRESS.md`](PROGRESS.md)에서 관리한다.

## 결과를 읽기 전에

- 후보 선정 결과와 이후 미관측 기간 검증 결과를 분리해서 본다.
- 총수익률 하나로 모델을 채택하지 않는다. fold 정합성, Rank IC, calibration,
  Sharpe, MDD, 거래 수와 factor 편향을 함께 본다.
- 정확한 실행 조건은 각 로컬 결과의 `config_snapshot.yaml`과
  `prediction_hash`를 기준으로 한다.
- 아래의 `probability` 분석은 사용자 화면에서 미래 확률로 단정하지 않고,
  **과거 유사 신호 구간의 상대 순위와 관측 결과**로만 해석한다.

## 1. Horizon 후보 선정 결과

2020~2022 선택 fold를 포함한 당시 설정에서 같은 백테스트 엔진으로 비교한
대표 후보이다. H5는 4개 fold, H10/H20은 3개 fold가 정확히 정렬됐다.

| Horizon | Triple Barrier | 총수익률 | CAGR | Sharpe | MDD | 거래 수 | Prediction hash |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| H5 | `u175/d150` | 126.44% | 22.18% | 1.088 | -15.12% | 827 | `f51893d6` |
| H10 | `u250/d225` | 92.32% | 23.83% | 1.139 | -16.07% | 386 | `7c362764` |
| H20 | `u375/d300` | 82.89% | 21.81% | 1.103 | -13.15% | 310 | `7493ede1` |

당시 비교에서는 H5가 총수익률, H10이 CAGR·Sharpe, H20이 MDD와 낮은 거래
빈도에서 상대적으로 나았다. 이는 **후보를 고른 구간의 결과**이며 최종 성능이나
미래 재현성을 뜻하지 않는다.

H5 내부 비교에서는 `u125/d100`이 총수익률 80.61%, Sharpe 0.914, MDD -18.82%,
1,251건이었고 `u175/d150`은 수익·위험 지표가 개선되면서 거래 수가 827건으로
줄었다. 선택된 H5의 ROC-AUC는 0.607, PR-AUC는 0.465, 일별 Rank IC 평균은
0.135, IC 양수 일자 비율은 86.38%였다.

## 2. Horizon 신호 비교

2021~2024 분석에서 세 horizon의 전체 확률값은 강하게 겹쳤지만, 좁은 상위 종목
집합에서는 차이가 커졌다.

| 비교 | Pearson 상관 | 일별 Rank 상관 평균 | Top-5 중복 | Top-10% 중복 |
| --- | ---: | ---: | ---: | ---: |
| H5-H10 | 0.963 | 0.939 | 50.45% | 72.95% |
| H5-H20 | 0.891 | 0.846 | 25.40% | 56.17% |
| H10-H20 | 0.962 | 0.945 | 50.30% | 74.11% |

H5-H20의 Top-5 중복이 25.40%로 가장 낮아 H20이 H5와 다른 후보를 더 많이
포착했다. 신호를 서비스에서 함께 보여줄 경우 방향 일치 여부를 설명 정보로 쓸 수
있지만, 사용자 성향만으로 종목을 제거하는 하드 제약으로 사용해서는 안 된다.

### 과거 상위 신호 구간

| Horizon | 구간 | 평균 실현수익률 proxy | 라벨 적중률 |
| --- | --- | ---: | ---: |
| H5 | 상위 1% / 5% | 0.61% / 0.44% | 57.82% / 53.01% |
| H10 | 상위 1% / 5% | 1.44% / 1.08% | 54.82% / 52.70% |
| H20 | 상위 1% / 5% | 2.64% / 2.21% | 52.55% / 51.05% |

긴 horizon은 이 표에서 평균 실현수익률 proxy가 컸지만 적중률 차이는 작았다.
따라서 이 수치를 사용자별 “상승 확률”로 번역할 수 없고, 표본 수·시장 구간과
calibration을 함께 제시해야 한다.

## 3. 편향과 factor-neutral 검증

- H10/H20은 momentum 20·60 노출이 강했다.
- 세 horizon 모두 작은 종목, 고변동성, 저유동성 방향의 기울기가 관찰됐다.
- 거래 기여는 KOSDAQ에 집중됐고, H20의 당시 KOSPI 기여는 음수였다.
- H5에서는 SPAC, H10/H20에서는 speculative proxy 노출이 상대적으로 두드러졌다.

### 중립화한 factor

실제 factor-neutral 종목 선택에서는 아래 **9개 종목별 exposure**에 대한 모델
점수의 선형 성분을 중립화했다. 연속형 값은 각 날짜의 전체 종목 안에서 계산한
백분위이고, 가격 기반 값은 신호 시점의 미래 정보가 들어가지 않도록 1거래일
lag를 적용했다.

| Exposure | 계산 기준 | 제거하려는 선택 편향 |
| --- | --- | --- |
| `size_pct` | 전일 종가 proxy의 날짜별 백분위 | 고가·저가 종목 및 규모 유사 편향 |
| `momentum_20_pct` | 전일 기준 20일 수익률의 백분위 | 단기 momentum 편향 |
| `momentum_60_pct` | 전일 기준 60일 수익률의 백분위 | 중기 momentum 편향 |
| `volatility_pct` | 전일 `Sigma`의 백분위 | 고변동성 종목 편향 |
| `liquidity_pct` | 전일까지의 `Close × Volume` 20일 평균 백분위 | 고·저유동성 종목 편향 |
| `is_preferred` | 종목명 기준 우선주 여부 | 우선주 편향 |
| `is_spac` | 종목명 기준 SPAC 여부 | SPAC 편향 |
| `is_distress` | 해당 시점의 거래정지 여부 | 관측 가능한 위험 상태 편향 |
| `speculative_proxy` | 규모 하위 30%이면서 변동성 상위 30%, 유동성 하위 30% | 소형·고변동·저유동 복합 편향 |

`size_pct`는 시가총액이 아니라 **전일 종가 proxy**이므로 엄밀한 size factor로
해석하면 안 된다. 유통주식 수를 포함한 point-in-time 시가총액 데이터가 확보되면
교체해야 한다.

### 중립화 방법

각 거래일마다 종목 횡단면에서 원래 모델 점수 `Prob`를 위 exposure들에 OLS
회귀하고, 설명되지 않은 잔차를 factor-neutral score로 사용했다. 원래
`Prob >= 0.65` 조건은 그대로 유지한 뒤, 조건을 통과한 종목만 잔차 백분위로 다시
정렬해 일별 top-5를 골랐다. 이후 원본과 동일한 `SwingStrategy`와
`VectorBTEngine` 청산 규칙으로 백테스트했다.

따라서 여기서 “제거”는 각 exposure와 모델 점수 사이의 **당일 선형 관계를
통제했다**는 의미다. 비선형·교호작용 노출이나 원래 threshold 통과 여부에 이미
반영된 편향까지 완전히 제거했다는 뜻은 아니다.

위 방식으로 만든 잔차 점수의 결과는 다음과 같다.

| Horizon | Raw 수익률 | 중립화 수익률 | Raw Sharpe | 중립화 Sharpe |
| --- | ---: | ---: | ---: | ---: |
| H5 | 107.95% | 69.24% | 1.064 | 0.865 |
| H10 | 77.14% | 54.72% | 1.107 | 0.898 |
| H20 | 68.72% | 57.16% | 1.102 | 0.985 |

중립화 후 성과가 약해졌으므로 기존 성과 일부는 momentum·size·liquidity 노출과
관련된다. 동시에 신호가 완전히 사라지지는 않았다. 통계적 유의성이 강하다고
단정할 근거는 부족하므로, 화면에서는 해당 노출을 근거·위험 정보로 함께 표시해야 한다.

### 포함하지 못한 factor와 한계

- `market`은 전체 유니버스 동일가중 일별 수익률로 수익률 attribution에는
  포함했지만, 같은 날짜 모든 종목에 공통인 값이라 종목별 횡단면 중립화에는
  넣지 않았다.
- KOSPI/KOSDAQ 소속 exposure는 point-in-time 시장 구분표가 없어 넣지 못했다.
  따라서 관찰된 KOSDAQ 집중이 중립화 결과에도 남을 수 있다.
- value·quality·profitability 같은 재무 factor는 당시 point-in-time 재무 데이터가
  없어 포함하지 않았다.
- 업종, beta, 거래대금 충격과 상장 시점 같은 노출도 통제하지 않았다. 그러므로
  중립화 후 남은 성과를 곧바로 독립적인 chart alpha로 해석하지 않는다.

## 4. 2025 final holdout 로컬 검증

2026-08-17에 확인한 로컬 산출물이다. 학습 구간은 2022-01-01~2024-12-31,
test는 2025-01-08~2025-12-31, 수수료는 0.105%, signal lag는 1거래일이었다.
두 결과 모두 fold·행 정합성 검사는 통과했다. benchmark는 외부 KRX 다운로드 실패로
동일 유니버스의 내부 동일가중 종가 수익률을 사용했다.

- H5 라벨: `u175/d150`, H20 라벨: `u375/d300`
- 전략: `prob_up >= 0.65` 중 일별 top-5 동일가중
- 공통 `data.version`: `d9b3625f6d86e8e77d06657fb3ef852fe38c3cd7a8aa6fa7be95572e098cf858`
- 두 실행 모두 `training.skip_validation: true`여서 별도 ML validation 결과가 없다.

| Horizon | 총수익률 | CAGR | Sharpe | MDD | 거래 수 | 승률 | Prediction hash |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| H5 | -3.04% | -2.99% | -1.774 | -3.36% | 15 | 33.33% | `764cbc74` |
| H20 | 2.77% | 2.72% | 1.082 | -1.00% | 8 | 62.50% | `6d2f77d3` |

같은 기간 내부 benchmark 총수익률은 약 25.1%였다. H5와 H20 모두 거래 수가 매우
적고 benchmark를 크게 밑돌았다. 특히 H5는 후보 선정 구간의 성과가 미관측 기간에
재현되지 않았다. H20의 양수 성과도 8건만으로 일반화할 수 없다. 별도 ML calibration
산출물도 없으므로 이 표만으로 일반적인 성능 우위를 결론 내리지 않는다. H5/H20 모델
파일과 profile 매핑은 배포 정본으로 registry에 고정하되, 모델 고정과 연구 효과 입증을
구분한다.

## 5. 심리 피처 A/B 결과 상태

고정 비교 러너의 입력·실행 방법은 [`ONBOARDING.md`](ONBOARDING.md)의 A/B comparison
절을 따른다. 실제 심리·뉴스 결합 원천 데이터로 실행한 결과는 아직 없다. 테스트
fixture 수치는 연구 결과로 기록하지 않는다.

## 6. 산출물 보관 규칙

- 재현 코드는 `experiments/`, 공유 템플릿은 `experiments/configs/`에 둔다.
- 예측·모델 캐시, 거래 내역, 일별 수익률, HTML과 전체 결과 폴더는 로컬 또는 팀의
  별도 스토리지에 둔다.
- 대표 결과만 이 문서에 데이터 기간, split, 비용, 핵심 지표, `prediction_hash`,
  `data.version`과 함께 추가한다.
- 새 결과는 후보 선정, holdout, robustness, ablation 중 성격을 명시한다.
- 자동 생성 report는 근거 산출물이지 진행 문서나 결과 정본이 아니다.
- 보존 중인 과거 자동 생성 report는 로컬 `legacy_screening/artifacts/`에서 확인한다.

기록 형식:

```text
실행일 / 실험명 / 목적
데이터 기간 / split / universe / 비용
config snapshot 위치 / prediction hash / data.version
ML 핵심 지표 / backtest 핵심 지표 / benchmark
결론 / 한계 / 다음 검증
```
