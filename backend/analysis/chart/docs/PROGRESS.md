# 차트 분석 진행 기록

남기는 단일 진행 기록이다. 실행법은 [`ONBOARDING.md`](ONBOARDING.md), 수치와 상세 해석은
[`EXPERIMENT_RESULTS.md`](EXPERIMENT_RESULTS.md)를 기준으로 한다.

## 시간순 기록

### 2026-05-22 ~ 2026-06-12 — 기반 구성과 데이터 점검

- 프로젝트 초기 구조와 chart 모듈 사용법을 구성했다.
- 가격 데이터 무결성 점검 도구를 추가하고 H5 LightGBM 기본 평가 기반을 마련했다.

### 2026-06 (2026-07-01 기준 정리) — 라벨·horizon 탐색

- Triple Barrier의 상·하방 multiplier screener를 만들고 라벨 분포와 기간 안정성을
  먼저 확인하도록 했다.
- H5 후보 `u125/d100`, `u175/d150` 등을 비교해 `u175/d150`을 대표 후보로 남겼다.
- 같은 절차를 H10과 H20으로 확장해 각각 `u250/d225`, `u375/d300` 후보를 선정했다.
- 단일 수익률 중심 평가를 calibration, Rank IC, fold alignment, Sharpe, MDD,
  거래 수를 함께 보는 방식으로 확장했다.
- horizon 신호 중복, 시장별 손익 기여, factor attribution과 factor-neutral
  backtest를 수행했다. 수익의 일부가 momentum·size·liquidity 노출과 관련되지만,
  factor 중립화 뒤에도 신호가 완전히 사라지지는 않는 것을 확인했다.

### 2026-07-04 — 저장소 구조 이관

- chart 블록을 현재 `backend/analysis/chart/` 구조로 옮기고 경로 참조를 정리했다.

### 2026-07-13 — 심리 피처 A/B 비교 기반 추가

- `stable/aggressive × baseline/treatment` 4개 런을 같은 표본·기간·시드·평가 함수로
  비교하는 러너를 추가했다.
- 실제 심리·뉴스 결합 입력은 아직 준비되지 않아 연구 질문에 대한 실측 결론은
  내리지 않았다.

### 2026-07-15 ~ 2026-07-17 — 학습·평가·백테스트 정합성 보강

- 학습, OOS 예측 캐시, ML 평가, 백테스트와 결과 대시보드를 현재 구조로 통합했다.
- 같은 날 entry/exit 충돌, 청산 상태, 평가 가격과 체결 가격, fold 경계와 MDD 계산을
  보완했다.
- 대용량 산출물은 로컬에 두고 대표 결과 요약만 Git으로 공유하는 정책을 정했다.

### 2026-07-20 ~ 2026-07-21 — 외부 피처와 누수 방지

- 뉴스·재무 피처를 원본 Alpha158과 분리해 결합하는 feature store 도구를 추가했다.
- `AvailableDate`, 적용 기간, 결측 정책과 금지 컬럼을 검증하도록 했다.
- 비교실험의 조인 키·모델 경로·baseline 피처 수를 고정하고, 라벨 purge 경계와
  정식 학습 라벨 예외 계약을 보강했다.

### 2026-08-14 — 6월 실험 결과 문서화

- multiplier screening, horizon 비교, factor 분석 결과를 하나의 회의용
  결과·로드맵 문서로 정리했다.

### 2026-08-17 — 문서 통합과 2025 holdout 상태 확인

- 완료 결과와 향후 계획이 섞여 있던 6월 로드맵을 폐기하고, 보존할 결과는
  결과 정본으로, 작업 이력은 이 문서로 통합했다.
- 로컬 2025 final holdout 산출물을 확인했다. H5는 총수익률 -3.04%, H20은
  +2.77%였지만 거래 수가 각각 15건과 8건뿐이라 최종 모델 판단 근거로는 부족하다.
- H5/H20 모델은 배포 registry에 반영됐지만, 적은 거래 수 때문에 holdout 성과의
  일반화는 보류했다. 실제 심리 피처 A/B 결과도 아직 확인되지 않았다.

## 기록 규칙

- 작업을 마친 날짜에 1~3개 bullet로 **변경·결과·남은 검증**만 추가한다.
- 계획만 있는 항목은 별도 계획서로 만들지 않고 위 `현재 상태`에 기록한다.
- 수치가 있는 결과는 결과 정본에 조건·기간·비용·hash와 함께 기록하고 여기서는
  결론만 링크한다.
- 자동 생성 report와 CSV는 진행 문서로 취급하지 않는다.
