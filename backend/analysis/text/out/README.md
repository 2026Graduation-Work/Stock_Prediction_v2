# 가치투자 피처 데이터셋 (일별)

`value_pipeline`이 생성한 **모델 입력용 일별 피처 테이블**입니다. 차트 블록(기술지표)과
`(ticker, date)`로 조인해 쓰는 것을 전제로 합니다.

> 이 디렉터리에서 **CSV와 이 README만 git으로 추적**합니다. 원본 일별 JSON
> (12,000+개)은 기사 제목 원문을 포함하고 용량이 커서 제외하며, 아래 명령으로
> 언제든 재생성할 수 있습니다.

## 파일

| 파일 | 종목 | 기간 | 행 수 | 감성 결측 |
|---|---|---|---|---|
| `features_005930_daily.csv` | 삼성전자 | 2017-01-01 ~ 2025-12-31 | 3,287 | 46 (1.4%) |
| `features_035420_daily.csv` | 네이버 | 2017-01-01 ~ 2025-12-31 | 3,287 | 285 (8.7%) |
| `features_005380_daily.csv` | 현대차 | 2017-01-01 ~ 2025-12-31 | 3,287 | 295 (9.0%) |
| `features_247540_daily.csv` | 에코프로비엠 | 2019-04-01 ~ 2025-12-31 | 2,467 | 1,762 (71.4%) |

행은 **달력일 기준**이라 주말·휴일이 포함되어 있습니다. 거래일만 필요하면 OHLCV와
조인하면 자연히 걸러집니다.

## 컬럼

**조인 키**: `ticker`(6자리 종목코드), `date`(YYYY-MM-DD)

**뉴스 (기준일 당일)**

| 컬럼 | 의미 |
|---|---|
| `news_sentiment` | KR-FinBERT 감성 평균 (-1 ~ +1) |
| `news_impact_score` | 영향력 1~10 (기사 수·감성 강도의 결정론 규칙) |
| `news_sentiment_std` | 기사 간 의견 분산 |
| `news_staleness` | 직전 10건 대비 단어 중복률 0~1 (Tetlock 2011) |
| `article_count` | 관련성 필터를 통과한 기사 수 |

**재무 (기준일 시점 공시된 사업보고서 = point-in-time)**

| 컬럼 | 의미 |
|---|---|
| `financial_health_score` | 재무 건전성 0~10 |
| `valuation_score` | 저평가 정도 0~10 |
| `financial_age_months` | 재무 신선도(개월) — 기준일 − 사업연도 종료월 |
| `per`, `pbr`, `roe`, `revenue_growth`, `debt_ratio`, `altman_z` | 축별 대표 지표 |

## 결측(NaN) 규약 — 조인 전 반드시 확인

- **`news_sentiment` 등 감성 4개가 NaN = "그날 관련 기사가 없었음"**입니다.
  **0으로 채우지 마세요.** 0.0은 "중립 기사가 있었다"는 뜻이라 의미가 다릅니다.
  LightGBM은 NaN을 네이티브로 처리하므로 그대로 넣으면 됩니다.
- `article_count`는 그런 날 **0**입니다(사실이므로 NaN이 아님). 결측 지시자로 쓰세요.
- 재무 지표의 NaN은 DART 계정 매핑 실패 또는 주가·주식수 결측입니다.

**에코프로비엠은 감성의 71%가 결측입니다.** 소형주라 조용한 날이 많아서이며,
연도별 커버리지는 2019년 12.7% → 2023년 60.3%(2차전지 급등기) → 2025년 21.9%입니다.
재무 피처는 전 기간 유효합니다.

## 제외된 행

`validation.ok == false` 중 **오염 행만** 제외했습니다(회계 항등식 위배, 룩어헤드,
단위 오류 등). '관련 기사 0건'뿐인 행은 재무 피처가 유효하므로 감성만 NaN으로 두고
유지합니다 — 행을 통째로 버리면 조용한 날이 많은 소형주가 데이터셋에서 사라져
대형주 편향이 생깁니다.

의도적으로 **제외한 컬럼**: `composite_score`, `value_investment_signal`, `confidence`.
다른 피처들의 고정 공식 조합이라 정보량이 0이고, 모델이 수작업 공식을 복제하게 됩니다
(사용자 화면 표시용으로만 씁니다).

## 재생성

```bash
cd backend/analysis/text
source ../../../.venv/bin/activate
bash run_all_batches.sh                                   # 4종목 일별 JSON (약 2시간)
python -m value_pipeline.features out/005930/005930_*.json --out out/features_005930_daily.csv
```

**생성 조건 (재현에 필요)**

| 항목 | 값 |
|---|---|
| `SHARES_ASOF_YEAR` | 2025 (발행주식수 스냅샷 — 액면분할 정합용) |
| LLM | 미사용 (배치는 강제 OFF, 숫자에 영향 없음) |
| 감성 백엔드 | KR-FinBERT (`snunlp/KR-FinBert-SC`) |
| 뉴스 원본 | 빅카인즈 수동 export (`data/<종목코드>/*.xlsx`) |
